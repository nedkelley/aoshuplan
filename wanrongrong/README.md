# 家庭奥数教案 · 四升五浅奥（36 课时）

面向**四升五、浅奥水平、能独立做高思导引 2–3 星题**的孩子，在家系统培训奥数的完整教案项目。

## 项目结构

```
奥数教案/
├── README.md              # 本说明
├── 总体规划.md            # 36 课时总表 + 学习路线 + 使用说明
└── 课时/
    ├── 模块一_计算/        # 课时 1–6
    ├── 模块二_数论/        # 课时 7–14
    ├── 模块三_应用题/      # 课时 15–24
    ├── 模块四_几何/        # 课时 25–29
    ├── 模块五_计数逻辑/    # 课时 30–33
    └── 模块六_综合/        # 课时 34–36
```

## 每个课时文件包含

- **模块 / 定位星级**：难度定位（大部分 ★3，逐步渗入 ★4）
- **教学目标**：这一课时孩子应掌握什么
- **前置知识**：需要先会什么
- **核心公式 / 概念**：家长先把原理吃透的部分
- **例题与详解**：待逐讲填充（原创题 + 全详解）
- **常见错误与讲解要点**：待逐讲填充

> 例题与详解、易错点两个板块当前为**占位**，后续按课时点名时逐讲生成。

## 使用节奏

- **每周 2 课时 = 18 周 ≈ 一个学期**。
- 每讲一次信息量不要贪多，孩子做不动 4 星就退回 3 星夯实。
- 做题流程：孩子先独立做 → 家长用教案详解对答案 → 讲透错题 → 记录错题本。
