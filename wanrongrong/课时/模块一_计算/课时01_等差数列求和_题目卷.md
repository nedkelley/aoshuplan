# 课时 1：等差数列求和（竞赛版）· 题目卷

---

## 一、知识点提醒

- 第 n 项 = 首项 + (n−1) × 公差
- 项数 =（末项 − 首项）÷ 公差 + 1
- 求和 =（首项 + 末项）× 项数 ÷ 2
- 性质：和 ÷ 项数 = 中间项（项数为奇数）；两项之差 ÷ 间隔 = 公差
- 进阶公式（Σn 表示 1+2+…+n，Σn² 表示 1²+2²+…+n²，Σn³ 表示 1³+2³+…+n³）：
  - Σn = n(n+1)/2
  - Σn² = n(n+1)(2n+1)/6
  - Σn³ = [n(n+1)/2]²
- 推导（选学）：(n+1)³ − 1 = Σ[(k+1)³−k³] = Σ(3k²+3k+1)，代入 Σk = n(n+1)/2，整理得 Σk² = n(n+1)(2n+1)/6。

---

## 二、例题（含讲解，先看题再对照方法）

### 例 1（★4）

求 1 到 200 中所有能被 7 整除的数之和。

- **讲解**：能被 7 整除：7,14,…,196，共（196−7）÷7+1 = 28 项；和 =（7+196）×28÷2 = **2842**。要点：把符合条件的数列成等差再套公式。

---

### 例 2（★5）

一个等差数列，前 8 项的和是 72，第 8 项是 16。求首项、公差，并求前 20 项的和。

- **讲解**：设首项 a、公差 d。第 8 项 = a+7d = 16 ①；前 8 项和 = 4(2a+7d) = 72 → 2a+7d = 18 ②。② − ① 得 a = 2，代回得 d = 2。前 20 项和 =（2+40）×20÷2 = **420**。要点：把"第 n 项"和"前 n 项和"列式联立。

---

### 例 3（★5）

计算 1³ + 2³ + 3³ + … + 10³。

- **讲解**：Σn³ = [n(n+1)/2]²。n = 10：10×11÷2 = 55，55² = **3025**。

---

### 例 4（★5+）

数列 5, 9, 13, 17, … 共有 50 项。求其中所有能被 3 整除的项之和。

- **讲解**：第 n 项 = 4n+1。要能被 3 整除：n ≡ 2（mod 3），即 n = 2,5,8,…,50，共 17 个。对应项 9,21,…,201 成等差（首 9、公差 12）；和 =（9+201）×17÷2 = **1785**。要点：先求项号 n 的同余条件，再找新等差。
