## 三、冲刺题详解

### 冲刺 1（★6）

= **50/101**。

- 推导：
  1. 分母 1×3、3×5、5×7、…、99×101，是两个相邻奇数相乘，一般项 = **1/[(2k−1)(2k+1)]**，k 从 1 到 50。
  2. 因为两个因数相差 **2**（不是 1），不能用基础裂项式，要用：**1/[(2k−1)(2k+1)] = (1/2)(1/(2k−1) − 1/(2k+1))**。
     验证：(1/2)(1/(2k−1) − 1/(2k+1)) = (1/2)×(2k+1 − (2k−1))/[(2k−1)(2k+1)] = (1/2)×2/[(2k−1)(2k+1)] = 1/[(2k−1)(2k+1)]。
  3. 逐项展开（每项都提出 1/2）：
     - 1/(1×3) = (1/2)(1 − 1/3)
     - 1/(3×5) = (1/2)(1/3 − 1/5)
     - 1/(5×7) = (1/2)(1/5 − 1/7)
     - ……
     - 1/(99×101) = (1/2)(1/99 − 1/101)
  4. 全部相加，提出公因数 1/2，中间项两两抵消：
     = (1/2)[(1 − 1/3) + (1/3 − 1/5) + … + (1/99 − 1/101)]
     = (1/2)(1 − 1/101)
     = (1/2)(100/101) = **50/101**。
- 要点：分母差 2 时，裂项后要补乘 **1/2**，别漏。

---

### 冲刺 2（★6+）

= **200/101**。

- 推导：
  1. 分母 1、3、6、10、… 是**三角数**：1 = 1，3 = 1+2，6 = 1+2+3，10 = 1+2+3+4，…，最后一项 = 1+2+…+100。
  2. 用公式 1+2+…+n = n(n+1)/2，所以 **1/(1+2+…+n) = 1/[n(n+1)/2] = 2/[n(n+1)]**。
  3. 每项再用裂项 2/[n(n+1)] = 2×(1/n − 1/(n+1))，逐项展开：
     - 第 1 项 1 = 2/(1×2) = 2×(1 − 1/2)
     - 第 2 项 1/3 = 2/(2×3) = 2×(1/2 − 1/3)
     - 第 3 项 1/6 = 2/(3×4) = 2×(1/3 − 1/4)
     - ……
     - 最后一项 1/(1+…+100) = 2/(100×101) = 2×(1/100 − 1/101)
  4. 全部相加，提出公因数 2，中间项两两抵消：
     = 2×[(1 − 1/2) + (1/2 − 1/3) + … + (1/100 − 1/101)]
     = 2×(1 − 1/101)
     = 2×100/101 = **200/101**。
