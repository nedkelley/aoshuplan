# 课时 7：整除特征（2/3/4/5/8/9/11）

- **模块**：模块二 · 数论基础
- **定位星级**：★3
- **预计**：1 课时

## 教学目标
掌握 2、3、4、5、8、9、11 的整除判定特征，能快速判断大数能否被某数整除。

## 前置知识
数的分解、位值概念。

## 核心公式 / 概念（整除特征）
- **2**：末位是偶数。
- **3 / 9**：各位数字之和能被 3 / 9 整除。
- **4**：末两位组成的数能被 4 整除。
- **5**：末位是 0 或 5。
- **8**：末三位组成的数能被 8 整除。
- **11**：奇数位数字和 与 偶数位数字和 之差能被 11 整除。
