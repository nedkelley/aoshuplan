## 知识结构（公共底座 + 按工种选修）

### ① 公共底座（投任一 AI 应用岗都要有）

**语言与工程**
- Python 熟练（硬门槛，绕不开；C# 底子两周到一个月）
- 后端：FastAPI/Flask、REST、Postgres/Redis、Docker
- Linux 命令行、Git、读报错日志（已有）

**LLM 核心概念（理解原理即可，不手推数学）**
- Transformer / Attention / Token / Embedding / 上下文窗口
- 采样参数：temperature、top-p、top-k、logit bias
- 预训练 / 微调(SFT) / 对齐(RLHF) / LoRA / 量化(int8/int4/FP16)
- 大模型的边界：幻觉、上下文长度、知识截止日期

**Prompt 与结构化输出**
- System prompt、few-shot、CoT、角色设定
- Function Calling / Tool Use、JSON 结构化输出（Agent 地基）

**RAG 全链路（面试问最多，吃透）**
- 解析 → 分块 → 向量化 → 存向量库 → 检索 → rerank → 生成
- 向量库：Milvus / pgvector / FAISS；embedding 选型
- RAG 评估：召回率、准确率

**Agent 与编排**
- 工具调用、多智能体、状态管理、循环终止
- LangChain / LangGraph / LlamaIndex / AutoGen / Dify / Coze
- MCP 协议（工具接入标准）

**模型服务化与部署**
- Ollama / vLLM / TGI、量化、显存估算、并发/吞吐权衡

### ② 按工种选修（挑 1–2 个主攻）

- **推理/部署** → TensorRT-LLM、CUDA 基础、GPU 调度、性能压测（C++ 是核心优势）
- **RAG/知识库** → 向量库深度、检索优化、召回评估、复杂文档解析
- **Agent** → LangGraph 状态图、MCP 生态、长任务编排
- **AIGC** → SD/ComfyUI、LoRA 训练图、多模态 API
- **解决方案/交付** → 某行业业务语言 + 方案写作 + PoC 代码

## 落点建议（结合苏州无锡）

1. **模型推理/部署工程师**——C++ 是稀有且对口的能力，招不到足够的人，41 岁不减分（重工程经验、轻年龄）。
2. **AI 解决方案/交付**——苏州无锡全是制造业/工业/物联网，要「能把大模型塞进生产场景的人」，老道 + 工程判断是稀缺资产。

中间那条 **RAG/Agent** 是通用跳板，作为公共底座里最先吃透的一块。
