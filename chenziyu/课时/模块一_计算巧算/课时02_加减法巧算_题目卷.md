# 课时 2：加减法巧算（凑整、拆数、带符号搬家）· 题目卷

---

## 一、知识点提醒

- **凑整**：把能凑成整十、整百、整千的数先放一起算。
- **带符号搬家**：移动数时带着前面的 + 或 − 号。
- **连续减 = 减去它们的和**：a − b − c = a − (b + c)。
- **拆数凑整**：把一个数拆成几部分去凑整（如 3 拆成 1+1+1，5 拆成 3+2）。
- **配对**：符号交替的算式，一加一减成对，先配对再算。

---

## 二、例题（含讲解）

### 例 1（★5）

计算 198 + 297 + 305。

- **讲解**：198+2=200，297+3=300，305−5=300：= 200 + 300 + 300 = **800**。要点：拆数凑整，先把每个数补到整百。

---

### 例 2（★5）

计算 645 + 155 − 145 + 245。

- **讲解**：带符号搬家配对：(645 − 145) + (155 + 245) = 500 + 400 = **900**。要点：加的和减的分开配。

---

### 例 3（★6）

计算 100 − 99 + 98 − 97 + … + 2 − 1。

- **讲解**：一加一减配成对：(100−99) + (98−97) + … + (2−1)，每组都等于 1，共 50 组 = **50**。要点：先配对再算。

---

### 例 4（★6）

计算 9 + 99 + 999 + 3。

- **讲解**：把 3 拆成 1+1+1：(9+1) + (99+1) + (999+1) = 10 + 100 + 1000 = **1110**。要点：一个数拆成几份去凑整十、整百、整千。
