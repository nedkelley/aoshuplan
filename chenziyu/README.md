# 二升三 奥数教案 · 项目说明

面向**二年级升三年级、走奥数思维拔高路线**的孩子，对标低年级竞赛（华杯/走美低年级组）的家庭系统培训教案。

## 项目结构

```
数学教案_二升三/
├── README.md              # 本说明
├── 总体规划.md            # 24 课时大纲 + 学习路线 + 使用说明
└── 课时/
    ├── 模块一_计算巧算/    # 课时 1–6
    ├── 模块二_图形空间/    # 课时 7–10
    ├── 模块三_典型应用题/  # 课时 11–17
    ├── 模块四_周长测量/    # 课时 18–20
    └── 模块五_逻辑趣题/    # 课时 21–24
```

## 标准（沿用上一项目）

每个课时生成两份文件：**题目卷**（例题内嵌讲解 + 练习/测试/冲刺留白）+ **答案详解**（答案 + 思路），并输出 .md 源文件 + .doc 可打印版。
- 例题内嵌讲解，末尾 2 道冲刺题（★6+）
- 紧凑排版，约 2 页 A4
- 每讲出完自检竞赛级难度（多步 / 需观察 / 技巧叠加 / 数字隐蔽）

## 使用节奏
每周 2 课时 = 12 周 ≈ 一个学期。孩子做不动就退回夯实，别赶进度。
